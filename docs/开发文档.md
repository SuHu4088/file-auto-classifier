## 1. 架构设计

### 1.1 设计理念

本项目采用 **三层分离架构**，将 GUI 界面、业务逻辑和配置数据完全分离，确保各层职责清晰、耦合度低，便于独立维护和扩展。

### 1.2 架构分层

```
┌─────────────────────────────────────────────────────────┐
│                    GUI 层 (gui/)                         │
│                                                         │
│  MainWindow  ←──── Qt 信号槽 ────→  FileClassifier     │
│      │                                                 │
│      ├── 视图渲染 (QTreeWidget, QTextEdit, ...)        │
│      ├── 事件处理 (拖拽、按钮点击、窗口关闭)             │
│      └── 用户交互 (QMessageBox, QFileDialog)            │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                  业务逻辑层 (core/)                     │
│                                                         │
│  FileClassifier (QThread)     FilePreviewer             │
│      │                           │                     │
│      ├── 文件扫描                ├── 预览数据生成        │
│      ├── 分类逻辑                └── 统计计算            │
│      └── 文件移动                                      │
│                  │                                      │
│                  ▼                                      │
│              FileUtils (工具函数)                        │
│              ├── get_files_in_folder()                  │
│              ├── move_file()                            │
│              ├── generate_new_filename()                │
│              └── format_file_size()                     │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                  配置层 (core/)                         │
│                                                         │
│  CategoryConfig                                         │
│      ├── EXTENSION_CATEGORIES (扩展名→类别映射)         │
│      ├── CATEGORY_COLORS (类别→颜色映射)                │
│      ├── get_category()                                 │
│      └── get_category_color()                           │
└─────────────────────────────────────────────────────────┘
```

### 1.3 数据流

#### 分类流程

```
用户选择文件夹
       │
       ▼
[GUI] browse_folder() / dropEvent()
       │
       ▼
[GUI] preview_files() ──→ [Core] FilePreviewer.preview()
       │                           │
       │                           ├── 扫描文件
       │                           ├── 按扩展名分组
       │                           └── 返回预览数据
       │
       ▼
[GUI] 显示预览树 ←── 预览数据
       │
       ▼
[GUI] start_classification() ──→ [Core] FileClassifier.run()
       │                              │
       │                              ├── 扫描文件
       │                              ├── 按类别分组
       │                              ├── 创建目标文件夹
       │                              ├── 遍历文件调用 move_file()
       │                              │    ├── os.rename() (原子操作)
       │                              │    └── copy2()+验证+remove() (跨盘)
       │                              │
       │                              └── 发送信号
       │                                    ├── progress_updated (进度)
       │                                    ├── log_added (日志)
       │                                    └── classification_completed (完成)
       │
       ▼
[GUI] 更新进度条 / 添加日志 / 显示统计
```

### 1.4 线程模型

```
┌──────────────┐                ┌──────────────────┐
│   主线程      │                │    工作线程        │
│  (GUI Event)  │                │  (FileClassifier) │
│               │   Qt Signals    │                  │
│  更新进度条   │ ←───────────── │  扫描文件         │
│  添加日志     │ ←───────────── │  移动文件         │
│  更新状态栏   │ ←───────────── │  检查 is_running  │
│               │                │                  │
│  停止按钮     │ ──────────────→ │  设置 is_running  │
│              │   设置标志变量   │  = False         │
└──────────────┘                └──────────────────┘
```

**线程安全策略：**
- 文件操作在工作线程中执行，不阻塞 GUI 事件循环
- 线程间通信仅通过 Qt 信号槽机制，不在工作线程中直接操作 UI
- 使用 `is_running` 标志变量实现优雅停止，不使用 `terminate()`

## 2. 模块说明

### 2.1 main.py — 程序入口

**职责：** 应用程序启动入口，负责创建 QApplication、加载样式表、显示主窗口。

```python
def main():
    app = QApplication(sys.argv)
    app.setStyleSheet(DARK_STYLE)
    window = MainWindow()
    window.show()
    sys.exit(app.exec())
```

**关键点：**
- `sys.path.insert` 确保模块导入路径正确
- 加载深色主题样式表
- 启动 Qt 事件循环

### 2.2 core/category_config.py — 分类配置

**职责：** 定义文件扩展名到分类类别的映射关系，以及各类别的显示颜色。

| 变量/函数 | 类型 | 说明 |
|-----------|------|------|
| `EXTENSION_CATEGORIES` | `dict[str, list]` | 类别名称到扩展名列表的映射 |
| `CATEGORY_COLORS` | `dict[str, str]` | 类别名称到十六进制颜色码的映射 |
| `get_category(extension)` | `function` | 根据扩展名返回类别名称 |
| `get_category_color(category)` | `function` | 根据类别名称返回颜色码 |

### 2.3 core/file_utils.py — 文件操作工具

**职责：** 提供文件系统操作的底层工具函数。

| 函数 | 参数 | 返回值 | 说明 |
|------|------|--------|------|
| `get_files_in_folder(path)` | `path: str` | `list[dict]` | 扫描文件夹，返回文件信息列表 |
| `ensure_folder_exists(path)` | `path: str` | `None` | 确保文件夹存在，不存在则创建 |
| `generate_new_filename(path)` | `path: str` | `str` | 生成不冲突的新文件名 |
| `move_file(src, dest, strategy)` | `src: str, dest: str, strategy: str` | `tuple[bool, str]` | 安全移动文件 |
| `format_file_size(bytes)` | `bytes: int` | `str` | 格式化文件大小显示 |

### 2.4 core/classifier.py — 分类器与预览器

**职责：** 实现文件分类的核心业务逻辑，包括多线程分类执行和同步预览。

#### FileClassifier 类

继承 `QThread`，在独立线程中执行文件分类操作。

| 方法 | 说明 |
|------|------|
| `__init__(folder_path, conflict_strategy)` | 初始化分类器参数 |
| `run()` | 线程入口，执行扫描→分组→移动的完整流程 |
| `stop()` | 设置停止标志，优雅终止分类操作 |

#### FilePreviewer 类

提供静态方法，同步执行文件预览扫描。

| 方法 | 说明 |
|------|------|
| `preview(folder_path)` | 扫描文件夹并返回分类预览数据 |

### 2.5 gui/main_window.py — 主窗口

## 3. API 文档

### 3.1 CategoryConfig API

#### `get_category(extension)`

根据文件扩展名返回所属分类类别。

```python
from core.category_config import get_category

category = get_category("mp4")
# 返回: "视频"

category = get_category("xyz")
# 返回: "其他"
```

**参数：**

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `extension` | `str` | 是 | 文件扩展名（带或不带点均可） |

**返回值：** `str` — 类别名称

#### `get_category_color(category)`

根据分类类别返回对应的显示颜色。

```python
from core.category_config import get_category_color

color = get_category_color("视频")
# 返回: "#FF6B6B"
```

### 3.2 FileUtils API

#### `get_files_in_folder(folder_path)`

扫描指定文件夹中的所有文件（不递归子目录）。

```python
from core.file_utils import get_files_in_folder

files = get_files_in_folder("/path/to/folder")
# 返回: [{"name": "test.mp4", "path": "/path/to/test.mp4", "size": 1024, "extension": "mp4"}, ...]
```

**返回数据结构：**

```python
[
    {
        "name": str,        # 文件名（含扩展名）
        "path": str,        # 完整路径
        "size": int,        # 文件大小（字节）
        "extension": str    # 扩展名（不含点，小写）
    },
    ...
]
```

#### `move_file(src_path, dest_folder, conflict_strategy)`

安全移动文件到目标文件夹。

```python
from core.file_utils import move_file

success, message = move_file("/src/test.txt", "/dest/", "rename")
# 成功: (True, "")
# 跳过: (False, "已跳过（文件已存在）")
# 失败: (False, "权限错误")
```

**参数：**

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `src_path` | `str` | — | 源文件完整路径 |
| `dest_folder` | `str` | — | 目标文件夹路径 |
| `conflict_strategy` | `str` | `"rename"` | 冲突策略：`"rename"` / `"skip"` / `"overwrite"` |

**返回值：** `tuple[bool, str]` — (是否成功, 消息)

**文件移动机制：**

```
                    ┌──────────────────┐
                    │ 处理目标路径冲突  │
                    │ (skip/overwrite/ │
                    │  rename)          │
                    └────────┬─────────┘
                             │
                    ┌────────▼─────────┐
                    │ 尝试 os.rename() │
                    │   (原子操作)      │
                    └────────┬─────────┘
                             │
                    ┌──── 成功 ──── 失败 ────┐
                    │                        │
                    ▼                        ▼
              返回成功            ┌───────────────────┐
                                  │ 跨文件系统回退:    │
                                  │ 1. copy2() 复制   │
                                  │ 2. 验证大小一致   │
                                  │ 3. remove() 删除  │
                                  └───────┬───────────┘
                                          │
                              ┌──── 成功 ──── 失败 ────┐
                              │                        │
                              ▼                        ▼
                          返回成功              返回错误信息
```

### 3.3 FileClassifier API

#### 信号

| 信号 | 参数类型 | 说明 |
|------|----------|------|
| `progress_updated` | `int` | 进度百分比 (0-100) |
| `status_updated` | `str` | 状态描述文本 |
| `log_added` | `str` | 日志消息 |
| `classification_completed` | `dict` | 分类结果数据 |

#### `classification_completed` 信号数据结构

```python
{
    "total": int,          # 文件总数
    "success": int,        # 成功移动数
    "failed": int,         # 失败数
    "skipped": int,        # 跳过数
    "categories": {
        "视频": {
            "count": int,      # 该类别文件数
            "size": int,       # 该类别总大小（字节）
            "files": [str]     # 成功移动的文件名列表
        },
        ...
    }
}
```

#### 使用示例

```python
from core.classifier import FileClassifier

classifier = FileClassifier("/path/to/folder", "rename")
classifier.progress_updated.connect(on_progress)
classifier.log_added.connect(on_log)
classifier.classification_completed.connect(on_done)
classifier.start()

# 停止
classifier.stop()
```

### 3.4 FilePreviewer API

#### `FilePreviewer.preview(folder_path)` (静态方法)

```python
from core.classifier import FilePreviewer

data = FilePreviewer.preview("/path/to/folder")
```

**返回数据结构：**

```python

    "total": int,
    "categories": {
        "视频": {
            "count": int,
            "size": int,
            "formatted_size": str,  # 如 "200.00 MB"
            "files": [str]          # 文件名列表
        },
        ...
    }
}
```

## 4. 开发规范

### 4.1 命名规范

遵循 PEP 8 编码规范：

| 类型 | 规范 | 示例 |
|------|------|------|
| 模块名 | 小写蛇形 | `file_utils.py` |
| 包名 | 小写蛇形 | `core`, `gui` |
| 类名 | 大驼峰 | `FileClassifier` |
| 函数/方法 | 小写蛇形 | `get_category()` |
| 变量名 | 小写蛇形 | `folder_path` |
| 常量 | 大写蛇形 | `EXTENSION_CATEGORIES` |
| 私有方法 | 前缀下划线 | `_internal_method()` |
| 信号 | 小写蛇形 | `progress_updated` |

### 4.2 导入规范

导入顺序：标准库 → 第三方库 → 项目内部模块，各组之间空行分隔。

```python
# 标准库
import os
import shutil

# 第三方库
from PySide6.QtWidgets import QMainWindow, QWidget
from PySide6.QtCore import QThread, Signal

# 项目内部
from core.classifier import FileClassifier
from core.file_utils import format_file_size
```

### 4.3 注释规范

- 模块级别：文件开头使用 docstring 描述模块用途
- 类级别：使用 docstring 描述类职责
- 函数级别：复杂函数使用 docstring 说明参数和返回值
- 行内注释：仅在逻辑不直观时添加，避免过度注释

### 4.4 错误处理

- 文件操作必须使用 `try-except` 捕获异常
- 区分 `PermissionError`、`FileNotFoundError`、`OSError` 分别处理
- 提供清晰的中文错误提示信息
- 异常不能导致程序崩溃，必须优雅恢复

### 4.5 线程安全

- 工作线程中**禁止**直接操作 UI 组件
- 线程间通信**必须**使用 Qt 信号槽机制
- 使用标志变量实现优雅停止，**禁止**使用 `QThread.terminate()`
- 共享数据需注意竞态条件

### 4.6 文件操作安全

- 移动操作优先使用 `os.rename()`（同文件系统原子操作）
- 跨文件系统回退使用 `copy2()` + 完整性验证 + `remove()`
- 复制后必须验证目标文件大小与源文件一致
- 验证失败时**不得**删除源文件

## 5. 扩展指南

### 5.1 添加新的文件类别

在 [core/category_config.py](../core/category_config.py) 中添加：

```python
EXTENSION_CATEGORIES = {
    # ... 现有类别
    "设计": ["psd", "ai", "sketch", "fig", "xd"],
}

CATEGORY_COLORS = {
    # ... 现有颜色
    "设计": "#F368E0",
}
```

无需修改其他任何文件，程序会自动识别新类别。

### 5.2 添加新的扩展名

在 `EXTENSION_CATEGORIES` 字典中，找到对应类别的列表，添加新扩展名即可：

```python
"视频": [
    "mp4", "mkv", "avi",
    # 添加新格式
    "ts", "m2ts", "vob",
],
```

### 5.3 自定义主题样式

修改 [gui/styles.py](../gui/styles.py) 中的 `DARK_STYLE` 字符串。支持所有 Qt StyleSheet 语法。

### 5.4 添加新的 UI 功能

1. 在 `gui/main_window.py` 的 `init_ui()` 中添加 UI 组件
2. 创建事件处理方法
3. 连接信号槽
4. 如需后台操作，在 `core/classifier.py` 中扩展逻辑

## 6. 测试指南

### 6.1 单元测试

建议为以下核心函数编写单元测试：

```python
# 测试 get_category()

# 测试 move_file() - 同文件系统

# 测试 format_file_size()
assert format_file_size(1024) == "1.00 KB"
assert format_file_size(0) == "0 B"
```

### 6.2 集成测试

- **分类流程测试**：创建包含各类文件的测试文件夹，执行完整分类流程
- **重复文件测试**：在目标文件夹预置同名文件，测试三种冲突策略
- **预览功能测试**：验证预览数据的准确性和完整性

### 6.3 边界测试

| 测试场景 | 预期结果 |
|----------|----------|
| 空文件夹 | 日志提示"未找到任何文件" |
| 仅含子文件夹 | 忽略子文件夹，日志提示无文件 |
| 大文件 (1GB+) | 正常移动，进度条正常更新 |
| 跨盘移动 | 使用 copy2+verify+remove 方案 |
| 权限不足 | 返回失败，提示"权限错误" |
| 文件被占用 | 返回失败，提示错误信息 |
| 分类中点击停止 | 优雅停止，显示已完成统计 |

## 7. 常见问题

### Q: 文件移动失败怎么办？

**A:** 常见原因及解决方案：
- 文件被其他程序占用 → 关闭占用程序后重试
- 权限不足 → 以管理员身份运行程序
- 磁盘空间不足 → 检查目标磁盘可用空间
- 跨盘移动缓慢 → 跨盘使用复制+删除方式，大文件耗时正常

### Q: 分类进度卡住不动？

**A:** 可能是正在处理大文件（跨盘复制），请耐心等待。如长时间无响应，点击「停止」按钮中断操作。

### Q: 预览显示的文件数量与实际不符？

**A:** 程序仅扫描文件夹根目录的文件，不递归子目录。子目录中的文件不会被分类。

### Q: 如何添加自定义文件类别？

**A:** 参考 [扩展指南](#51-添加新的文件类别)，修改 `core/category_config.py` 即可。
